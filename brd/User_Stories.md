# User Stories

## Product Manager

As a Product Manager, I want to identify top-performing product categories so that I can prioritize future investments.

---

## Marketing Manager

As a Marketing Manager, I want to understand customer purchasing behavior so that I can design targeted campaigns.

---

## Sales Manager

As a Sales Manager, I want to monitor monthly revenue trends so that I can improve sales planning.

---

## Operations Manager

As an Operations Manager, I want to identify delivery delays so that logistics performance can be improved.

---

## Business Analyst

As a Business Analyst, I want interactive dashboards so that stakeholders can easily monitor KPIs.
